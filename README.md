# 📊 Data Visualization - Superstore Sales Analysis

## 📁 Dataset
Used: `Superstore.csv`

## 🛠 Tool
Tool Used: **Tableau** / **Power BI**

## 📌 Objective
Analyze and visualize sales data to uncover trends, outliers, and actionable insights using visual storytelling.

## 📈 Key Visuals
- Sales & Profit by Region
- Category-wise Performance
- Top 10 Customers by Profit
- Profit Trend Over Time
- Discount vs Profit Analysis
- Map of Sales by State

## 📍 Business Insights
- West region has high sales but low profitability — investigate further.
- Technology is the highest grossing category.
- California contributes the most to overall profit.
- Discounts beyond 20% drastically reduce profit margins.
